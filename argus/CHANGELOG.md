# Changelog

## v0.3 — 2026-10-03 (переработка ядра)

### ⚡ Скорость и качество сканирования
- **TOP_PORTS расширен с 30 до ~110** реально значимых портов (RDP, VNC, базы данных, Kubernetes, MQTT, SCADA и т.д.). Причина бага «выдал только 80 порт» устранена.
- **Конкурентность stealth-режима: 50 → 800–2000** параллельных соединений; убран искусственный `sleep(0.01)` на каждый порт. Полный скан 65535 портов занимает минуты вместо часов.
- Корректное чтение баннеров: убрана `\r\n`-провокация, ломавшая молчаливые сервисы (RDP/VNC становились невидимыми).
- TLS/HTTP-фингерпринт теперь выполняется для **всех** потенциальных web/TLS-портов (HTTPS на 80/8080/8443 больше не теряется).
- Прогресс-бар при больших сканах; флаг `--ports "20-100,443,3389"` — произвольные диапазоны вместо фиксированных режимов.

### 📊 Максимальный вывод
- Каждый открытый порт: `port | state | service | product+version | TLS (протокол, шифр, CN, SAN, срок сертификата) / HTTP (status, Server:) | banner | os_hint`.
- Новая сводная таблица **«Предположение об ОС/аппаратной платформе»** (`guess_os`: Windows / Linux / RouterOS / Cisco / Synology / NAS — с уровнем уверенности и списком сигналов).
- Консоль и HTML-отчёт без обрезки: показываются **все** открытые порты (раньше — top-50).

### 🔒 Безопасность кода (ликвидированы по современным методам)
- Убран `verify=False` в 3 местах (MITM на результатах разведки) → единый `core/net.py` с честной TLS-верификацией.
- **Path traversal** при сохранении отчётов (`target/../evil`) → санитизация имени цели + regex-валидация.
- Ручной XSS-экран в HTML заменён на `html.escape()` + CSP-meta-тег в отчёте.
- **SSRF через конфиг AI**: Ollama-host проверяется на loopback/private-адреса.
- Ограничение размера ответа crt.sh (защита от memory exhaustion), таймауты на все сетевые операции, гарантированное закрытие сокетов.
- Валидация `severity` у находок и диапазона портов у пользователя.
- Deprecated `datetime.utcnow()` → aware UTC; SQLite-соединения через context manager.

### 🧹 Архитектура и дубликаты
- **Удалён модуль `github_recon`** полностью (без токена возвращал 403/429 — мёртвый код). В инструменте не осталось кода, требующего API-токены; AI работает только через локальную Ollama.
- ~250 строк копипасты if/elif в `argus.py` → декларативный реестр `MODULES` + общие `_run_module/_run_all`.
- **Дедупликация находок** через `Finding.dedup_key()` (sha256 от payload): повторные прогоны + кэш больше не плодят дубли.
- Исправлен режим `q`: при пустом кэше запускает полную разведку вместо тихого «нет данных».
- DNS-разведка различает NXDOMAIN/NoAnswer; добавлены SPF/DMARC-проверки с severity.
- `tech_fingerprint` с fallback на `http://`; `subdomain_brute` с лимитом времени прогона.
- Пути к `data/`, `reports/`, `ai/` — абсолютные относительно файла модуля (работа из любой директории).
- Надпись **AUTO → ARGUS** везде: баннер, меню, консоль, HTML-отчёты («ARGUS v0.3»).
